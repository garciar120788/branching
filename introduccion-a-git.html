🌱 Introducción a Git

Lo básico para empezar a controlar versiones de tu código

¿Qué es Git?

Git es un sistema de control de versiones. Sirve para guardar el historial de cambios de tus archivos (normalmente código), poder volver atrás si algo sale mal, y trabajar en equipo sin pisarse el trabajo unos a otros.

No hay que confundirlo con GitHub: Git es la herramienta que corre en tu computadora, y GitHub es un sitio web donde puedes subir tus repositorios de Git para compartirlos o respaldarlos.

Conceptos clave

repositorioCarpeta con tu proyecto que Git está vigilando
commitUna "foto" guardada de tus cambios en un momento dado
branch (rama)Una línea de trabajo separada para probar cosas sin afectar lo principal
remoteUna copia del repositorio en otro lugar (como GitHub)

Comandos básicos

1. Iniciar un repositorio

git init

2. Ver el estado de tus archivos

git status

3. Preparar cambios para guardarlos

git add archivo.txt
git add .   # agrega todos los cambios

4. Guardar los cambios (hacer un commit)

git commit -m "Descripción breve del cambio"

5. Ver el historial de commits

git log

6. Crear y cambiar de rama

git branch nueva-funcion
git checkout nueva-funcion

# o en un solo paso:
git checkout -b nueva-funcion

7. Conectar con un repositorio remoto (ej. GitHub)

git remote add origin https://github.com/usuario/repositorio.git
git push -u origin main

8. Traer cambios del remoto

git pull

Un flujo de trabajo típico

git status          # ver qué cambió
git add .           # preparar cambios
git commit -m "..." # guardar cambios
git push            # subir al remoto

Esto se repite una y otra vez mientras trabajas: modificas archivos, los agregas, haces commit, y subes (push) cuando quieres compartir o respaldar tu avance.

Consejo para empezar

No te preocupes por memorizar todo. Con git status, git add, git commit y git push puedes cubrir el 90% del trabajo diario. El resto (ramas, merges, resolver conflictos) se aprende poco a poco practicando.
